## 🧠 Overview

**Plex-Earth** is a geospatial design extension created for CAD professionals who need to work with real-world imagery, terrain information, and geographic data directly inside their design environment. The software connects CAD drawings with aerial imagery, satellite maps, elevation data, and geographic reference information, helping engineers and designers understand the actual conditions surrounding a project.

The application is designed to work alongside popular CAD platforms such as AutoCAD, Civil 3D, and BricsCAD. Instead of moving between separate mapping and design applications, users can bring geographic context into their existing CAD workflow and continue working with familiar drawing tools.

A central part of Plex-Earth is its imagery functionality. Users can select a project area, choose an available imagery provider, specify the desired resolution, and bring the resulting imagery into a properly georeferenced drawing. This makes it easier to evaluate existing buildings, roads, vegetation, property areas, infrastructure, and other visible site conditions.

The software also provides terrain-related functionality. Elevation information can be converted into contours, TIN meshes, points, or Civil 3D surfaces. These models can be used to examine topography, evaluate slopes, understand elevation changes, and perform preliminary earthwork calculations.

Another important component is historical imagery. Plex-Earth allows users to examine imagery from different periods, making it possible to compare how a location has changed over time. This can be useful when reviewing construction progress, previous site conditions, development history, or changes to surrounding infrastructure.

The combination of CAD drawings, imagery, terrain, and geographic positioning makes **Plex-Earth** a practical tool for preliminary engineering and planning workflows. It can provide additional site context before detailed design begins and help users make better-informed decisions using visual information from the real world.

## Additional Information for Windows Users

**Plex-Earth** is designed for 64-bit Windows systems and operates as an extension for compatible CAD applications. Its purpose is to add geographic and environmental context to drawings without requiring users to abandon their existing CAD workflow.

One of the main advantages of the software is the ability to work with aerial and satellite imagery directly inside a drawing. After establishing the geographic position of the project, users can select an area of interest, choose an available imagery source, and create imagery that corresponds to the real-world location. Larger imagery mosaics can also be prepared for complete sites or extended project corridors.

Terrain functionality provides additional information for projects where elevation is important. Plex-Earth can use elevation services, GeoTIFF data, survey information, existing points, and contour geometry to create usable terrain representations. Depending on the workflow, the resulting information can be displayed as contour polylines, TIN meshes, elevation points, or Civil 3D surfaces.

Terrain analysis can provide additional insight into the characteristics of a site. Users can examine elevation differences, slope conditions, and surface direction, which can be useful during early planning and feasibility studies. Terrain information can also be combined with imagery to create a more realistic representation of the existing environment.

The historical imagery functionality provides another way to investigate project locations. Instead of relying only on the latest available image, users can compare different time periods and review how a site has developed. This can be helpful for construction monitoring, infrastructure studies, development analysis, and understanding previous site conditions.

Plex-Earth can also be used with Google Earth-related workflows. CAD designs can be transferred into geographic visualization environments using supported KML and KMZ workflows, allowing project concepts to be viewed in their surrounding real-world context.

The software is suitable for a variety of professional applications, including civil engineering, land development, transportation, infrastructure, utilities, telecommunications, renewable-energy projects, municipal planning, architecture, and urban development.

Its combination of imagery, terrain modeling, geographic referencing, historical data, and CAD integration makes **Plex-Earth** useful during preliminary design stages when engineers and designers need a better understanding of the environment in which a project will be developed.
